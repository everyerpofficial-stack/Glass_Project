# Glass Quote Suite

Quotation, proforma invoice and work-order management for a glass and aluminium
business. React 19 + TanStack Start on the front end, with Google Sheets (via a
Google Apps Script web app) as the backend of record.

---

## Requirements

- [Bun](https://bun.sh) 1.2+ — the project uses `bun.lock`
- Node.js 22+ (Vite 8 / nitro toolchain)

## Getting started

```sh
bun install
bun run dev          # http://localhost:8080
```

## Scripts

| Script              | What it does                                      |
| ------------------- | ------------------------------------------------- |
| `bun run dev`       | Vite dev server on port 8080                      |
| `bun run build`     | Production build (client + nitro server bundle)   |

## Architecture notes

**Calculation.** All pricing, area, tax and discount maths lives in
`src/lib/calc.js` and is treated as verified and frozen. `src/lib/gq.ts` is a
data layer only — it calls into `calc.js` and contains no formulas of its own.
Anything that changes a number is a breaking change.

**Backend.** `public/code.gs` is the Google Apps Script web app that reads and
writes the Google Sheet. It is deployed separately in the Apps Script editor;
Vite only serves the file. The Sheets column layout and the invoice numbering
scheme are part of the contract with existing data — treat them as fixed.

**Error handling.** `src/server.ts` wraps TanStack Start's server entry so that
an SSR crash renders `error-page.ts` instead of a raw h3 500 JSON body.
`error-capture.ts` hooks `console.error` and the global error events so the
original stack survives h3 swallowing it.

**Build.** `vite.config.ts` composes the plugins directly: Tailwind v4, tsconfig
path resolution, TanStack Start (with `server.entry` pointed at `src/server.ts`),
nitro, and React — in that order. nitro defaults to `cloudflare-module`; set
`NITRO_PRESET` to target another host.

## Deployment

```sh
bun run build
```

The build emits a nitro server bundle for the resolved preset. For Cloudflare
Workers, deploy the generated output with Wrangler. To target Vercel, Netlify or
Node instead, set `NITRO_PRESET` before building.

Separately, deploy `public/code.gs` as a Google Apps Script web app and point the
app at its URL from the Settings page.
