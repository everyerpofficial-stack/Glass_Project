# Agent guide — Glass Quote Suite

## What this project is

A glass and aluminium quotation / proforma invoice manager. TanStack Start
(React 19 + Vite) on the front end, Google Apps Script + Google Sheets as the
backend of record.

## Ground rules

1. **Never change the calculation engine.** `src/lib/calc.js` holds the pricing,
   area, tax and discount formulas and is treated as verified. `src/lib/gq.ts`
   delegates to it and must not reimplement any formula. If a number looks
   wrong, report it — do not "fix" it.
2. **Never change the backend contract.** `public/code.gs` (Apps Script), the
   Sheets column layout, and the invoice/quote numbering scheme are fixed.
3. `src/routeTree.gen.ts` is generated by the TanStack router plugin. Don't edit
   it by hand.
4. Routes follow TanStack Start file-based routing — see `src/routes/README.md`.
   Don't introduce `src/pages/` or `app/layout.tsx` (Next.js/Remix conventions).

## Before you commit

```sh
bun run lint
bun run build
```

## Git

Prefer additive commits on a branch. Avoid rewriting published history
(force-push, rebase/amend/squash of pushed commits) on `main`.
